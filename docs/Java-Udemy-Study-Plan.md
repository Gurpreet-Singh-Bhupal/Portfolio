## Course structure at a glance

The course has **62 sections** grouped into five logical blocks:

| Block | Sections | Video time | Purpose |
|-------|----------|------------|---------|
| **A — Core Java + exercises** | 1–32 | ~31 hrs | Foundations through concurrency, files, tips |
| **B — New features (optional)** | 34 | ~3 hr 18 min | Java 10 through Java 24 (reference) |
| **C — Interview review guide** | 35–52 | ~20 hrs | Revision of core topics (overlaps Block A) |
| **D — Spring ecosystem** | 53–61 | ~9.5 hrs | Spring, Boot, Maven, JPA, REST API |
| **E — Misc** | 33, 62 | ~4 min | Overview + congratulations |

### Why video time ≠ real study time

This course is **hands-on**. Almost every concept section includes:

- **Exercise statements** — try before watching solutions
- **Puzzles** — short challenges to test understanding
- **Coding Exercise sets** (10 sets) — dedicated practice sections
- **Section quizzes** — quick checks after major topics
- **JShell + Eclipse** — you must type code, not only watch

| Study style | Multiplier on video | Total effort (recommended path) |
|-------------|---------------------|----------------------------------|
| Light (watch-heavy, skip some puzzles) | ~1.2× | ~48–52 hrs |
| **Recommended** (code along, most exercises) | ~1.4–1.6× | **~55–65 hrs** |
| Thorough (all sections + all exercises) | ~1.5–1.7× | ~85–95 hrs |

## How to study properly (daily routine)

### Golden rules

1. **Never binge-watch without coding.** Pause and type every example in JShell or Eclipse.
2. **Do exercises before solutions.** When a lecture says "Exercise Statements," pause and try it yourself first.
3. **One section at a time.** Mark complete only after exercises, not just after video.
4. **Use flashcards** when the course says "DO NOT SKIP — FLASH CARDS."
5. **Take one rest day per week** to avoid burnout (plans below assume 6 study days/week).

### Suggested split per study session

#### At 2 hours/day

| Block | Time | Activity |
|-------|------|----------|
| Watch | 45 min | Lecture + pause to note key terms |
| Code | 60 min | JShell / Eclipse exercises and puzzles |
| Review | 15 min | Quiz or re-read one concept |

#### At 3 hours/day

| Block | Time | Activity |
|-------|------|----------|
| Watch | 60 min | Lectures at normal or 1.1× speed |
| Code | 90 min | Exercises + coding exercise sets |
| Review | 30 min | Quiz + flashcards / short notes |

#### At 4 hours/day

| Block | Time | Activity |
|-------|------|----------|
| Watch | 75 min | Lectures (can use 1.25× on revision sections) |
| Code | 2 hrs | Full exercise sets + extra practice |
| Review | 45 min | Quizzes, flashcards, summarize in your own words |

## Tips for success

1. **Build a small notebook** — one page per topic (variables, loops, OOP, collections). Write examples in your own words.
2. **Redo the multiplication table project** from Section 3–4 without looking — good sanity check.
3. **After Section 32**, build one tiny console app (e.g. todo list or expense tracker) before Spring.
4. **Section 61 REST project** — push to GitHub; link it from your portfolio if relevant.
5. **Stuck on install?** Use Section 2 troubleshooting; don't lose a whole day — ask in the in28minutes community.
6. **Interview Guide (35–52)** works best at **1.25× speed** after you've done the main sections once.
7. **Consistency beats intensity** — 2 hrs every day for 5 weeks beats 8 hrs once a week.
